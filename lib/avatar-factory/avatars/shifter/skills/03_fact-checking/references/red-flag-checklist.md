# Reference: Red-Flag Checklist

## Warning Signs That a Claim Might Be False

This checklist defines the signals that should trigger heightened scrutiny during fact-checking. A single red flag does not mean a claim is false, but it demands deeper verification.

---

### Source-Level Red Flags

| Flag | Description | Action |
|------|-------------|--------|
| **Anonymous or vague attribution** | "Experts say," "Some believe," "It is widely known" | Demand named source or remove claim |
| **Circular citation** | Source A cites Source B which cites Source A | Trace to primary; if circular, flag |
| **Predatory or fake journal** | Academic source from unknown publisher | Check DOI, indexing, peer-review status |
| **Satire or opinion presented as news** | Source is clearly labeled opinion or satire | Do not cite as factual source |
| **Domain mimicry** | URL looks like reputable source but is not | Verify domain ownership |
| **No publication date** | Source lacks any timestamp | Treat as unverified background only |

---

### Content-Level Red Flags

| Flag | Description | Action |
|------|-------------|--------|
| **Round numbers** | "Exactly 10,000," "Precisely 50%" | Verify; real data rarely produces round numbers |
| **Too perfect a story** | Narrative fits ideological frame without complication | Search for counter-evidence |
| **Extreme recency** | Claim about event that "just happened" with full analysis | Check if analysis was pre-written or speculative |
| **Emotional superlatives** | "Worst ever," "Unprecedented," "First time in history" | Verify with historical data |
| **Missing methodology** | Statistical claim without explanation of how derived | Request methodology or downgrade claim |
| **Cherry-picked time frame** | Graph or stat uses unusual start/end dates | Check if standard time frame changes conclusion |

---

### Draft-Level Red Flags

| Flag | Description | Action |
|------|-------------|--------|
| **Lone wolf source** | Important claim supported by only one source | Find corroboration or flag as unconfirmed |
| **Quote too good** | Quote perfectly captures the column's thesis | Check if quote is real or paraphrased |
| **Statistic without rival** | Column cites one statistic while ignoring contradictory official data | Address contradiction or remove claim |
| **Implausible precision** | Prediction given to exact decimal ("GDP will grow 2.47%") | Check if source supports precision or if rounded |
| **Misattributed expertise** | Person cited as expert in field outside their actual domain | Correct attribution or find appropriate expert |

---

### Verification Red Flags

| Flag | Description | Action |
|------|-------------|--------|
| **Source vanished** | URL was accessible during drafting but dead at verification | Attempt archive retrieval immediately |
| **Paywall shifted** | Source was accessible but now requires subscription | Note access limitation; do not bypass |
| **Correction issued** | Source has published a correction since drafting | Verify if correction affects column's claim |
| **Retraction published** | Academic paper or official report retracted | Remove claim; note retraction in log |

---

### Scoring

Count red flags per draft:
- **0-2 flags**: Standard verification depth
- **3-5 flags**: Enhanced verification (re-verify 50% of claims even if already checked)
- **6+ flags**: Halt verification; recommend operator review of source quality before proceeding
